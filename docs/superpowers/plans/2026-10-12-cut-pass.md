# Plan A, the cut: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut every frame and every audio clip of a video in one ffmpeg pass, read a fragmented MP4 through a progressive copy, and keep a black opening frame out of a still.

**Architecture:** `media.rs` gains four functions: a whole-video frame cut, a whole-video audio cut, a fragment check, and a progressive copy. `index.rs` cuts the whole video once and slices the file lists per window, so one window costs no ffmpeg call at all. The index run takes the store folder, so it can read a copy. `thumb_jpeg` keeps its job, and a new `probe_offset` picks the time of a still.

**Tech Stack:** Rust 2024, ffmpeg and ffprobe from `media::FFMPEG` and `media::FFPROBE`, sqlite-vec, llama.cpp through the vendored `llama-cpp-2`.

**Spec:** `docs/superpowers/specs/2026-10-12-cut-batch-search-design.md` section 3.

## Review Focus

Five input classes the spec implies but no task's tests exercise. Each one gets its test in the task named beside it.

1. **A window that runs past the end of the audio track.** The test clip holds 23.1 s of audio and 30.1 s of video, so the last six windows hold frames alone. The next index run must not stop. Test in Task 4.
2. **A video with no audio track at all.** The run must give frame records and no audio record. Test in Task 5.

4. **A still request after the probe window.** A request past four seconds keeps its own time. Test in Task 10.

/// Cut every frame of a video at `rate` frames a second.
///
/// One ffmpeg call covers the whole video, so a plan with many windows pays
/// for the seek once. The caller slices the list by time, because frame number
/// `n` counts from one and sits at `(n - 1) / rate`.
pub fn cut_frames(video: &Path, rate: f64, dir: &Path) -> Result<Vec<PathBuf>> {
    std::fs::create_dir_all(dir)?;
    let pattern = dir.join("f%05d.jpg").to_string_lossy().to_string();
    let args = vec![
        "-y".into(),
        "-i".into(),
        video.to_string_lossy().to_string(),
        "-vf".into(),
        format!("fps={rate}"),
        "-q:v".into(),
        "2".into(),
        pattern,
    ];
    run_ffmpeg(args, "extracting frames")?;
    let files = read_media(dir, &["jpg", "jpeg", "png"])?;
    if files.is_empty() {
        bail!("no frame came from {}", video.display());
    }
    Ok(files)
}
```

/// Cut the audio of a whole video into one-second 16 kHz mono WAV clips.
///
/// One ffmpeg call covers the whole track. Clip number `k` counts from zero
/// and covers `[k, k + 1)`, so the caller slices the list by time. A video with
/// no audio track gives an empty list.
pub fn cut_audio(video: &Path, dir: &Path) -> Result<Vec<PathBuf>> {
    if !has_audio(video) {
        return Ok(Vec::new());
    }
    std::fs::create_dir_all(dir)?;
    let pattern = dir.join("a%05d.wav").to_string_lossy().to_string();
    let args = vec![
        "-y".into(),
        "-i".into(),
        video.to_string_lossy().to_string(),
        "-vn".into(),
        "-ac".into(),
        "1".into(),
        "-ar".into(),
        "16000".into(),
        "-f".into(),
        "segment".into(),
        "-segment_time".into(),
        "1".into(),
        "-reset_timestamps".into(),
        "1".into(),
        pattern,
    ];
    run_ffmpeg(args, "extracting audio")?;
    let found = read_media(dir, &["wav"])?;
    let mut kept = Vec::new();
    for path in found {
        let bytes = std::fs::read(&path)?;
        if wav_has_samples(&bytes) {
            kept.push(path);
        } else {
            let _ = std::fs::remove_file(&path);
        }
    }
    Ok(kept)
}
```

/// The frames of one span, from the list of a whole-video cut.
///
/// Frame `i` of the list sits at `i / rate`, and the span `[from, from + window)`
/// takes the frames inside it. A span that runs past the list takes what is left.
pub fn frames_in(cut: &[PathBuf], from: f64, window: f64, rate: f64) -> Vec<PathBuf> {
    let first = (from * rate).round().max(0.0) as usize;
    let last = ((from + window) * rate).round().max(0.0) as usize;
    let end = last.min(cut.len());
    if first >= end {
        return Vec::new();
    }
    cut[first..end].to_vec()
}

/// The clips of one span, from the list of a whole-video cut.
///
/// Clip `k` of the list covers `[k, k + 1)`, and the span takes every clip that
/// touches it. A span past the end of the audio takes none, because a video
/// often holds less audio than video.
pub fn clips_in(cut: &[PathBuf], from: f64, window: f64) -> Vec<PathBuf> {
    let first = from.floor().max(0.0) as usize;
    let last = (from + window).ceil().max(0.0) as usize;
    let end = last.min(cut.len());
    if first >= end {
        return Vec::new();
    }
    cut[first..end].to_vec()
}
```

        let at = self.window_at;
        let from = self.windows[at];
        let rate = self.plan.frame_rate();

    /// Cut every frame and every clip of the video, one time.
    ///
    /// One window of a plan costs no ffmpeg call after this cut. A video with a
    /// short audio track cuts fewer clips than frames, and a window past the
    /// audio end holds frames alone.
    fn cut_media(&mut self) -> Result<()> {
        if !self.frames_cut.is_empty() || !self.clips_cut.is_empty() {
            return Ok(());
        }
        self.clear_dir();
        self.dir = work_dir(0);
        std::fs::create_dir_all(&self.dir)?;
        let rate = match self.plan.mode {
            crate::plan::Mode::Window => self.plan.frame_rate(),
            crate::plan::Mode::Fine => FRAME_RATE,
        };
        let frame_dir = self.dir.join("frames");
        self.frames_cut = media::cut_frames(&self.source, rate, &frame_dir)?;
        // Fine mode always holds audio records. Window mode holds them only
        // when the plan asks for them.

        if wants_audio {
            let audio_dir = self.dir.join("audio");
            self.clips_cut = media::cut_audio(&self.source, &audio_dir)?;
        }

    fn cut_batch(&mut self) -> Result<()> {
        if self.phase == Phase::Done || self.starts().is_empty() {
            self.phase = Phase::Done;
            return Ok(());
        }
        self.cut_media()?;
        if self.phase == Phase::Windows {
            self.files = self.window_files();
            self.batch_from = self.at();
            if self.files.is_empty() {
                bail!("no media came from the window at {} s", self.windows[self.window_at]);
            }
            return Ok(());
        }
        let at = self.at();
        let (count, step) = match self.phase {
            Phase::Frames => (FRAME_BATCH, FRAME_STEP),
            Phase::Audio => (AUDIO_BATCH, AUDIO_SECONDS),
            Phase::Windows | Phase::Done => unreachable!(),
        };
        let starts = self.starts();
        let last = (at + count).min(starts.len()) - 1;
        let to = (starts[last] + step).min(self.duration);
        let _ = to;
        let whole = match self.phase {
            Phase::Frames => &self.frames_cut,
            Phase::Audio => &self.clips_cut,
            Phase::Windows | Phase::Done => unreachable!(),
        };
        let end = (at + count).min(whole.len());
        self.files = whole[at..end].to_vec();
        self.batch_from = at;
        if self.files.is_empty() {
            if self.phase == Phase::Audio {
                // A video without an audio track is normal.
                self.phase = Phase::Done;
                return Ok(());
            }
            bail!("no frames came from {}", self.video.display());
        }
        Ok(())
    }

/// True when an MP4 holds fragmented media.
///
/// The walk reads the top level boxes. A fragmented file holds one `moof` box
/// for each fragment, and a plain file holds none. A file that is not an MP4
/// falls out of the walk and reads as plain.
pub fn is_fragmented_mp4(path: &Path) -> Result<bool> {
    use std::io::{Read, Seek, SeekFrom};

    let mut file = std::fs::File::open(path)
        .with_context(|| format!("open {}", path.display()))?;
    let len = file.metadata()?.len();
    let mut at = 0u64;
    while at + 8 <= len {
        file.seek(SeekFrom::Start(at))?;
        let mut head = [0u8; 8];
        if file.read_exact(&mut head).is_err() {
            return Ok(false);
        }
        let size = u32::from_be_bytes([head[0], head[1], head[2], head[3]]) as u64;
        if &head[4..8] == b"moof" {
            return Ok(true);
        }
        let step = match size {
            0 => len - at,
            1 => 16,
            _ => size,
        };
        if step < 8 {
            return Ok(false);
        }
        at += step;
    }
    Ok(false)
}
```

/// The name of the progressive copy of one video.
///
/// The name holds the source name and a hash of the full path, so two videos
/// with one name in two folders do not share a copy.
fn copy_name(video: &Path) -> String {
    let mut hash: u64 = 0xcbf29ce484222325;
    for byte in video.to_string_lossy().to_lowercase().bytes() {
        hash ^= u64::from(byte);
        hash = hash.wrapping_mul(0x100000001b3);
    }
    let stem = video
        .file_stem()
        .and_then(|part| part.to_str())
        .unwrap_or("video");
    format!("{stem}_{hash:016x}.mp4")
}

/// True when the copy exists and it is not older than its source.
fn copy_is_fresh(copy: &Path, video: &Path) -> bool {
    let (Ok(copied), Ok(source)) = (copy.metadata(), video.metadata()) else {
        return false;
    };
    let (Ok(copied), Ok(source)) = (copied.modified(), source.modified()) else {
        return false;
    };
    copied >= source
}

/// Rewrite a fragmented MP4 as a progressive MP4, and give back the copy.
///
/// A copy that is not older than its source stands, so a re-cut skips the
/// rewrite. The copy holds the same streams, and the index run reads it.
pub fn progressive_copy(video: &Path, media: &Path) -> Result<PathBuf> {
    std::fs::create_dir_all(media)?;
    let copy = media.join(copy_name(video));
    if copy_is_fresh(&copy, video) {
        return Ok(copy);
    }
    let args = vec![
        "-y".into(),
        "-i".into(),
        video.to_string_lossy().to_string(),
        "-c".into(),
        "copy".into(),
        "-movflags".into(),
        "+faststart".into(),
        copy.to_string_lossy().to_string(),
    ];
    run_ffmpeg(args, "rewriting a fragmented mp4")?;
    Ok(copy)
}
```

/// The average luma of the frame at one time, from the signalstats filter.
///
/// The filter writes its numbers as metadata, so `metadata=print:file=-` puts
/// them on the standard output. A time past the end of the video gives a fault,
/// because the filter then reports nothing.
pub fn luma(video: &Path, at: f64) -> Result<f64> {
    let args = vec![
        "-y".into(),
        "-ss".into(),
        format!("{at}"),
        "-i".into(),
        video.to_string_lossy().to_string(),
        "-frames:v".into(),
        "1".into(),
        "-vf".into(),
        "signalstats,metadata=print:file=-".into(),
        "-f".into(),
        "null".into(),
        "-".into(),
    ];
    let out = Command::new(FFMPEG)
        .args(&args)
        .output()
        .context("run ffmpeg for the luma")?;
    let text = String::from_utf8_lossy(&out.stdout);
    let line = text
        .lines()
        .find(|line| line.contains("lavfi.signalstats.YAVG="));
    let value = line
        .and_then(|line| line.split('=').nth(1))
        .and_then(|value| value.trim().parse::<f64>().ok());
    value.with_context(|| format!("no luma came from {} at {at} s", video.display()))
}
```

/// The times a thumbnail probe tries, in seconds.
///
/// The list is Google's (`VideoThumbnails.kt:35-62`).
pub const PROBE_OFFSETS: [f64; 6] = [0.0, 0.2, 0.5, 1.0, 2.0, 4.0];
/// A frame below this average luma reads as black.
pub const BLACK_LUMA: f64 = 16.0;

/// The first probe offset at or after `at` that holds a still that is not black.
///
/// A request past the last offset keeps its own time, so the probe costs
/// nothing after the opening of a video. When every candidate is black the last
/// one stands, because a black still beats no still.
pub fn probe_offset(video: &Path, at: f64) -> Result<f64> {
    let mut last = at;
    for offset in PROBE_OFFSETS.into_iter().filter(|offset| *offset >= at - 0.001) {
        last = offset;
        if luma(video, offset)? >= BLACK_LUMA {
            return Ok(offset);
        }
    }
    Ok(last)
}

/// The time of one still, with the black-frame probe.
///
/// The probe runs one time for each video in the life of the process, because
/// it costs one ffmpeg call for each offset it tries. A request past the probe
/// window keeps its own time and fills no map.
fn pick_thumb_time(chosen: &mut HashMap<String, f64>, video: &Path, at: f64) -> f64 {
    let last = media::PROBE_OFFSETS[media::PROBE_OFFSETS.len() - 1];
    if at > last {
        return at;
    }
    let key = video.to_string_lossy().to_string();
    if let Some(picked) = chosen.get(&key) {
        // A later request inside the window still reads the picked still, so
        // the page shows one picture of the opening.
        return picked.max(at);
    }
    match media::probe_offset(video, at) {
        Ok(picked) => {
            chosen.insert(key, picked);
            picked
        }
        Err(_) => at,
    }
}
